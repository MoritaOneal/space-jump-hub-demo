# Space Jump Hub — Demo pública

Aplicación web/PWA para la gestión de una academia de baloncesto.

Esta versión está preparada para una demostración académica pública. No usa la base de datos real de la academia, no contiene credenciales y utiliza únicamente datos ficticios.

## Funciones principales

- Gestión de alumnos y fichas deportivas
- Control de asistencia por turnos
- Alertas de faltas y cumpleaños
- Planificación anual de entrenamientos
- Sesiones interactivas con cronómetros y diagramas
- Modo cancha
- Evaluaciones físicas, técnicas y táctico-cognitivas
- Historial y seguimiento individual
- Reportes diarios y mensuales
- Diseño responsive para PC y celular

## Demo

Incluye alumnos, asistencias, evaluaciones y planes ficticios. Los cambios se guardan únicamente en localStorage del navegador.
